Part A: HTTP Server Routes (Port 3000)

  • GET / Welcome Page GET
  • GET /books Book Records (JSON) GET
  • GET /about About Library GET
  • GET /home Static File via FS GET
  • POST /add-book Add New Book POST

Part B: Express.js REST API Endpoints (Port 4000)

  • GET /books - Retrieve all books in catalog GET
  • GET /books/:id - Retrieve single book record by ID GET
  • POST /books - Create a new book record (HTTP 201) POST
  • PUT /books/:id - Update existing book record by ID PUT
  • DELETE /books/:id - Remove book record from catalog DELETE
